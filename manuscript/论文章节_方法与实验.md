3 方法

3.1 总体架构

本文提出双分支模型。数据分支以多层感知机（MLP）处理每块板卡的 100 点电气测量向量，提取数据特征 h_d；知识分支从电路故障知识图谱学习 TransE 嵌入，按故障类别查询邻域子图并做均值池化，经可学习投影得到类别知识原型 P_c；融合层为多维门控注意力层，将数据特征与知识信号逐维加权融合；分类器将融合特征映射到故障类别。训练分两阶段：先在图谱上预训练 TransE 嵌入，再冻结图谱嵌入端到端训练下游模型。

图 1　知识图谱引导的门控注意力融合诊断架构

3.2 数据分支

设 x_i ∈ R¹⁰⁰ 为第 i 个样本的测量向量，测试点数为 100。数据特征 h_d ∈ R⁶⁴ 计算为 h_d = MLP(x_i)，其中隐层维度取 64。MLP 采用两层结构，捕获测试点测量值之间的非线性交互。

3.3 知识分支

采用 TransE 从知识图谱学习实体与关系嵌入，将有效三元组 (h, r, t) 建模为 e_h + e_r ≈ e_t。对每个故障类别 c，查询知识图谱中对应故障节点的邻域子图，提取 1 跳邻域内的实体集合 E_c。类别知识原型通过对这些实体的 TransE 嵌入取均值并经线性投影得到：

P_c = W_p · (1/|E_c|) Σ_{e∈E_c} e_e

其中 W_p ∈ R⁶⁴ˣ¹²⁸ 为可学习投影矩阵，P_c ∈ R⁶⁴ 为类别 c 的知识原型。故障节点的邻域包含其故障族、现象与故障元件，因此同类不同位置的故障（如 R1 开路与 R6 开路）具有可区分的子图。

3.4 门控注意力融合

给定数据特征 h_d 与类别知识原型 {P_c}，先通过软检索聚合得到样本级知识信号：

h_k = Σ_c a_c P_c,   a_c = softmax(h_dᵀ P_c / τ)

随后两个特征向量经层归一化以缓解尺度差异，门控网络计算逐维权重 α ∈ [0,1]⁶⁴：

α = σ( W_g [h_d'; h_k'] + b_g )

融合特征为逐维凸组合：

h_f = α ⊙ h_d' + (1 − α) ⊙ h_k'

每个 α_j 控制局部的权衡：α_j → 1 时模型在第 j 维信任数据信号，α_j → 0 时依赖知识。与固定权重的拼接或相加融合不同，α 由输入自适应决定，从而允许模型在样本充分的维度上依靠数据、在样本不足的维度上依靠知识。融合特征 h_f 经全连接分类器输出类别概率。

3.5 训练策略

采用两阶段训练：阶段一在图谱上预训练 TransE 嵌入至收敛；阶段二冻结图谱嵌入，端到端训练数据分支、知识投影、门控模块与分类器，使用交叉熵损失。

3.6 知识图谱的可观测表现层（用于未见故障诊断）

为使知识图谱能够支持未见故障诊断，本文在图谱中引入「可观测表现层」（manifestation layer），形成两跳语义路径：

fault → has_phenomenon → phenomenon → manifests_as → manifestation

其中「现象」（phenomenon）为图谱中已有的故障症状描述，「可观测表现」（manifestation）为可在电气量上直接测量的物理属性，共 8 维：直流工作点偏移、交流频响偏移、支路电流异常、测量波动、拓扑断连、节点钳位、电阻性参数偏移、相邻节点等电位。该映射由图谱遍历自动导出，且**属性在多个故障之间共享**——例如 R1 开路与 R6 开路、R2 虚焊均表现为「直流工作点偏移」，只是故障元件不同。

在此基础上采用直接属性预测（DAP）完成零样本识别。训练阶段在可见故障上学习属性检测器 p(a_j | x)，每个属性带有可学习向量表示，与数据特征同样经逐维门控融合后判定该属性是否存在；测试阶段对候选故障类别 c 计算属性匹配得分：

s(c) = Σ_j [ a_cj · log p_j(x) + (1 − a_cj) · log(1 − p_j(x)) ]

其中 a_cj 为图谱给出的「类别 c 是否具有属性 j」的指示位，取得分最高者为诊断结果。由于检测器学习的是「电压失压」「频响偏移」这类跨故障共享的物理概念，其可迁移至训练中从未出现的故障类别。

4 实验设置

4.1 数据集

电路仿真。由于真实产线 ICT 测量记录受数据保密与标注成本限制，本文采用基于改进节点分析（MNA）的电路仿真生成测量数据。MNA 是 SPICE 仿真器的核心求解算法，对线性电路精确求解基尔霍夫方程（在分压网络与 RC 频响上验证了求解精度）。被测电路为一个模拟信号调理板，含 16 个元件与 7 个测试节点。

故障库。定义 22 类故障，覆盖 ICT 常见电气故障模式，且分布在电路的不同位置，包括开路 4 类（R1/R3/R4/R6）、短路到地 4 类（R2/R5/R7/R10）、电容参数漂移 3 类（C1/C3/C5）、电容缺件 2 类（C2/C4）、虚焊 3 类（R2/R4/R9）、桥接 3 类（节点 3-4、4-5、5-6）与间歇性故障 3 类（R2/R4/R6）。故障库规模由后文的覆盖度标定实验确定：需保证每个物理属性至少有 3 个可见故障类别作为正例，否则属性检测器无法学到可迁移概念。此外，所有故障在纳入前均通过可测性检验（要求其在测量空间中的偏离量显著高于元件容差引起的波动），物理上不可测的故障（如因并联低阻元件而几乎无影响的虚焊）被剔除。

物理真实性。注入两类不确定性：蒙特卡洛元件容差，所有非元件参数按 ±5% 高斯分布扰动；测量噪声，对测量向量叠加信噪比 20 dB 的高斯噪声。

测量向量。每个样本的 100 点测量向量由 7 维直流工作点节点电压、90 维交流频响幅值（6 个测试节点 × 15 个频率点）、3 维关键支路电流构成。每类 400 样本，共 8800 样本，经 z-score 标准化。

4.2 少样本与零样本设定

少样本设定：从每个故障类别随机抽取 k 个标注样本作为训练集，k ∈ {5, 10, 20, 50}，验证集与测试集保持完整规模。为保证不同模型与消融变体之间的严格可比，所有实验在构建数据加载器之前重置随机流，使各配置面对完全相同的测量噪声序列与批量打乱顺序。

零样本设定：从 22 类中划出 3 类作为未见类别，训练时完全剔除，测试仅在未见类别中分类（候选集为这 3 类，随机猜测水平 33.3%）。为保证评估可复现，按属性覆盖度分层抽样 10 个留出折，每个折运行 5 个随机种子。

4.3 对比方法

B1（MLP）：仅使用测量数据的 MLP 分类器。B2（KG 原型）：数据特征与类别知识原型的余弦相似度分类，无门控融合。Ours（门控融合）：完整模型。零样本对比中另设随机属性矩阵对照，即对类别-属性矩阵作行置换（保持属性密度与向量多重集不变，仅打乱「类别→属性」的对应关系），用于检验知识内容是否真正起作用。

消融变体包括：融合机制（拼接 A1、相加 A2、固定权重 A3）、知识分支（移除 C1、自由可学习原型 C2）、知识信号（硬检索 B1 消融、均匀常数 B2 消融）、子图范围（0 跳 D1、2 跳 D2）与预训练（随机嵌入 E1）。

4.4 评估指标与统计分析

主指标为总体准确率。每个配置以 5 个随机种子训练 5 次，报告均值与标准差；统计检验采用种子级或折级配对 t 检验，显著性阈值 α = 0.05。

4.5 实验环境与超参数

TransE 嵌入维度 d_k = 128，间隔 γ = 1.0，学习率 0.01，训练 80 轮。数据分支 MLP 为两层（100 → 128 → 64），隐层维度 d_h = 64。训练学习率 10⁻³，批次大小 64（零样本实验为 128），Adam 优化器，验证集早停。硬件为 NVIDIA GeForce RTX 5070 GPU。

5.5 未见故障的零样本诊断

4.2 节的零样本设定下，随机猜测水平为 33.3%。作为对照，若直接以类别知识原型作为类条件向量交由共享打分器（即不引入可观测表现层），零样本准确率低于随机猜测，说明仅靠 TransE 嵌入的几何结构不足以支撑跨类别迁移。引入 3.6 节的可观测表现层后，模型在可见故障上学习 8 维物理属性的检测器（可见类属性检测准确率 92.7%），再按属性组合匹配未见故障，结果如表 3。

5.6 属性覆盖度标定：知识图谱零样本能力的启用条件

为定量回答「需要多大的故障库才能支撑零样本诊断」，本文定义属性覆盖度 min_cov 为：对所有属性取「该属性在可见故障集中的正例类别数」的最小值。min_cov 衡量的是属性检测器能学到的概念有多牢固——若某属性仅有一个可见正例类别，检测器必然退化为识别该单个类别，而非学习可迁移的物理概念。

在原始的 8 类故障库上，全部 56 种 3 类留出组合中，min_cov = 0 的有 53 个（零样本准确率 35.3%），min_cov = 1 的有 3 个（29.1%），没有任何组合能达到 min_cov ≥ 2。也就是说，8 类故障库从未进入过零样本可用的区间。将故障库扩展至 22 类、并按「每个属性至少 3 个正例类别」原则做平衡设计后，可用留出折达到 min_cov = 2 的 750 个与 min_cov = 3 的 314 个，零样本准确率随之从 29.1% 提升至 54.9%。

由此可给出可操作的故障库规模准则。设属性维度为 A、平均每类属性数为 r，则要在留出 U 个类别后仍保证 min_cov ≥ 3，可见类别数需满足 n_seen ≥ 3A / r。本文 A = 8、r ≈ 2.5，得 n_seen ≥ 10，加上留出的 3 类共约 13 类；但由于「测量波动」「相邻节点等电位」等属性仅由特定故障机理产生（来源较窄），需刻意为其配置正例，实际采用 22 类故障库。这一准则说明：扩展故障库时，属性覆盖的均衡性比单纯的类别数量更重要。
